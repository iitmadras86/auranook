# Migration Notes

This directory contains the original static HTML, CSS, JS, and image assets of the Auranook website before the Next.js migration.

## Original Structure
- `original-site/`: Contains all `.html` pages and their corresponding asset folders.
- `js/`: Legacy JavaScript files.
- `images/`: Original image assets from the Auranook repo.
- `css/`: Any standalone CSS files (if they existed, although Tailwind via CDN was primarily used).

These files serve as a visual and functional reference during the Next.js migration and should not be deleted until launch.
